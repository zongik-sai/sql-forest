# 집중모드: 화면 가림과 일시정지

## 요구의 정확한 구현 범위
다른 탭/창/프로그램으로 전환하여 이 학습 창의 포커스가 사라지거나 document가 hidden이면 학습 화면을 가리고 멈춘다. 다른 프로그램이 실행 중이라는 이유만으로 정지하지 않는다. 웹앱은 다른 앱 목록, 다른 탭 주소, 분할화면의 모든 창, 두 번째 모니터의 시선을 알 수 없다. 도구 설명에 이를 명확히 기록한다. 외부 앱 감시·프로세스 검사·키보드 차단을 추가하지 않는다.

## 상태기계
상태: active, paused, readyToResume. 학습 세션 시작 시 visible && document.hasFocus()인 경우에만 active.
- visibilitychange(hidden), window.blur, pagehide → 즉시 paused, 가림 표시, 입력/제출/타이머/애니메이션 잠금.
- focus 또는 visibilitychange(visible) → visible && hasFocus일 때 readyToResume. 자동 재개 금지.
- '학습 계속하기' → visible && hasFocus 재확인, active.
- 수동 휴식 → paused. 돌아오기 방식은 동일.

로그인 redirect는 학습 세션 전에 수행하여 시작 화면을 잠그지 않는다. 앱 내부 에디터 포커스 이동은 window blur가 아니므로 중단하지 않는다. 브라우저 메뉴·개발자도구·OS 대화상자 등도 포커스 손실을 일으킬 수 있으므로 벌점을 주지 않는다. 전체화면은 선택 버튼이고 필수가 아니며 우회 방지 수단으로 주장하지 않는다.

## 가림과 정지 구현
- 최상위 불투명 overlay(z-index 충분히 높음), 배경 blur만 사용 금지. '학습이 일시정지되었습니다. 돌아오면 계속할 수 있습니다.' 표시.
- 학습 루트에 inert 적용, aria-hidden 적절히 관리. resume dialog로 focus trap, 재개 후 이전 의미 있는 포커스 복원. 가림 중 에디터 핫키·단축키 제출도 무효화.
- activeSeconds는 active 상태에서만 누적. hidden 시 마지막 delta 확정 후 time anchor를 비운다. 복귀할 때 숨긴 시간을 더하지 않는다.
- 애니메이션/CSS transition/자동 진행/오디오/동영상/타이머를 멈춘다. 비활성 상태에서는 SQL 실행 요청을 차단한다.
- SQL이 이미 실행 중이면 Worker를 종료하고 DB를 기준 스냅샷으로 복원한다. 실행 전 수정 샌드박스 상태는 스냅샷으로 보존한다. 요청 generation을 변경해 늦은 결과를 무시한다. 학생에게 '실행이 중단되었습니다. 다시 실행해주세요.' 표시.
- 입력 초안·조작 상태·힌트 단계는 보존하며 진행중 활동을 오답이나 완료로 자동 처리하지 않는다.
- 페이지 새로고침 후 저장한 단계와 초안을 복구하고 사용자 클릭으로 다시 학습을 시작한다.

이 기능은 집중을 돕는 UI다. 모든 외부 앱 탐지, 학생 감시, 부정행위 차단을 보장하지 않는다. 문서가 숨겨진 순간 OS가 표시한 마지막 화면이나 캡처까지 웹앱이 지울 수 있다는 보장도 하지 않는다.
