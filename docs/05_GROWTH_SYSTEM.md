# 레벨 0~99: 씨앗에서 숲으로

## 목표
학습할 때마다 정원이 자라는 경험을 제공한다. 힌트·오답·속도에 따른 벌점은 없다. 실제 학습 기록과 게임 레벨은 별개다. 레벨99는 과정 전체를 경험했다는 뜻이며 SQLD 합격·완전 숙달을 뜻하지 않는다. 6시간 과정 안에서 레벨99 도달 가능해야 한다.

## 성장 단계: 모든 정수 레벨에 이름이 있다
| 레벨 | 성장 단계 | 시각 변화 |
|---|---|---|
| 0 | 잠든 씨앗 | 흙 위의 씨앗 한 알 |
| 1~9 | 깨어난 씨앗 | 씨앗이 열리고 뿌리가 자람 |
| 10~19 | 새싹 | 흙에서 줄기와 첫 잎이 나옴 |
| 20~29 | 어린 풀 | 잎과 작은 주변 풀이 늘어남 |
| 30~39 | 작은 묘목 | 중심 줄기와 가지가 생김 |
| 40~49 | 자라는 나무 | 줄기가 굵어지고 잎이 풍성해짐 |
| 50~59 | 튼튼한 나무 | 가지가 뻗고 나무 그늘이 생김 |
| 60~69 | 꽃피는 나무 | 꽃·열매·새가 추가됨 |
| 70~79 | 작은 숲 | 옆에 두세 그루의 나무가 자람 |
| 80~89 | 넓어지는 숲 | 다양한 나무와 길이 생김 |
| 90~98 | 울창한 숲 | 숲의 깊이·다양성·색감이 증가 |
| 99 | 나의 SQL 숲 완성 | 전체 정원 완성·완료 배지 |

각 구간 안에서도 레벨마다 잎 수·가지 길이·배경 식물·색 등 최소 한 요소가 연속 변화한다. 100개 이미지 파일을 만들지 말고 SVG/HTML/CSS의 결정적 파라미터로 구현한다. 지역별 장식은 단원 배지로 추가한다. 사용자 상태에 따라 동일 장면이 재현된다.

## 경험치: 최대 9,900 XP
`level = min(99, floor(totalXP / 100))`. 시작은 XP0/Lv0. 다음 레벨까지 `100-(totalXP%100)` XP이며 Lv99에서는 '성장 완료'. 표시 경험치 상한은 9,900이다.

| 지급 사건 | 수량 | 사건당 XP | 총 XP | 지급 조건 |
|---|---:|---:|---:|---|
| 핵심 활동 완료 | 48 | 100 | 4,800 | 독립 정답 또는 안내 후 의미 있는 수행 완료 |
| 체크포인트 문항 최초 해결 | 36 | 50 | 1,800 | 원문 또는 대응 변형 문항을 처음 정답 처리 |
| 단원 완료 | 12 | 100 | 1,200 | 4활동 완료+체크포인트 2/3 이상 |
| 최종 진단 문항 참여 완료 | 12 | 100 | 1,200 | 답 제출·채점 후 해당 해설 확인, 정오답 무관 |
| 과정 마무리 | 1 | 900 | 900 | 12단원 완료+모든 체크포인트 해결+최종 진단 완료 |
| 합계 | | | 9,900 | |

처음 진단·힌트 클릭·로그인·단순 체류·반복 실행·자유 실습·도전 복습은 기본 XP를 지급하지 않는다. 도전 모드는 별도 배지·숙련 기록만 제공한다. U12 미션도 48개 활동 안에 포함된다. 최종 진단은 공식 시험 점수가 아니다.

단원 해제는 2/3이지만 숲 완성은 36개 체크포인트 전부 해결해야 한다. 마지막에 미해결 체크포인트만 짧게 복습하는 '숲 완성 복습'을 제공한다. 정답 공개 후에는 대응 변형 문제를 해결해야 해당 문항 XP가 지급된다. 이 복습 시간은 기존 단원별 체크포인트 시간 및 U12 복습 흐름 안에 포함하며 재도전에 따라 360분보다 길어질 수 있다. 마무리 XP는 진단을 한 번 더 본다고 반복 지급하지 않는다.

## 안내 학습 인정
핵심 활동에서 정답을 본 경우 바로 완료·XP를 주지 않는다. 예: SQL을 직접 실행하고 결과의 핵심 행/열을 올바르게 선택, 조인 쌍 직접 연결, 정규화된 표를 재조립하는 후속 행동을 수행하면 '안내 학습 완료'로 인정한다. 힌트 사용만으로 XP를 줄이지 않는다. completion_kind는 independent/guided를 유지한다. 체크포인트의 정답 조건은 완화하지 않는다.

## 사건 식별과 중복 방지
보상 ID는 `activity:U01-A01`, `checkpoint:U01-Q01`, `unit:U01`, `final:F01`, `course:complete`처럼 안정적으로 지정한다. variant/모드/정답 시도 횟수는 같은 논리 보상 ID를 공유한다. XP entitlement 버전을 contentVersion과 분리한다. 문구 변경이나 콘텐츠 버전 증가로 같은 활동 보상을 다시 지급하지 않는다.

로그인 사용자는 서버 award_xp RPC를 통해 보상을 받는다. 클라이언트가 XP 액수·레벨을 전달해 결정하지 않는다. RPC가 로그인 ID, reward_catalog의 허용 ID·XP, prerequisite 상태를 확인하고 INSERT ON CONFLICT DO NOTHING으로 원장을 기록한다. 원장 합계를 진실값으로 삼고 클라이언트는 캐시한다. 오프라인은 '동기화 대기' 임시 성장 표시 후 온라인에서 재검증한다. 데모는 같은 규칙의 로컬 원장을 사용한다.

클라이언트 SQL 채점을 서버가 다시 실행하지 않으므로 학습 증거를 완전한 시험 보안으로 검증하는 시스템은 아니다. RLS와 원장 중복 방지는 서로의 데이터 접근과 일반 중복 지급을 막는 범위다.

## 배지·피드백
단원 배지 12개: 데이터 탐험가, 관계 설계자, 조회 입문자, 조건 탐정, 함수 조합가, 집계 분석가, 조인 연결자, 서브쿼리 탐험가, 순위 설계자, 변환 탐험가, 데이터 관리자, SQL 숲 완성자. 기본 배지는 단원 완료로 지급하며 반복 중복 지급하지 않는다.

추가 배지: '다시 해냈어요'(오답 후 재도전 성공), '스스로 풀었어요'(도전 3개 성공), '끝까지 연결했어요'(통합 미션 완료). 추가 XP는 없다. 연속 출석·순위표·속도 경쟁·실패 생명 수·랜덤 유료 보상은 넣지 않는다.

## 테스트 사례
- XP0→Lv0; XP99→Lv0; XP100→Lv1; XP9,899→Lv98; XP9,900→Lv99.
- U01 활동 4개+체크포인트3개+단원 완료=650 XP/Lv6(50%). U01~U12의 동일 수량 합계=7,800XP/Lv78. 최종 진단12문항 후=9,000XP/Lv90. 마무리 보상 후=9,900XP/Lv99.
- 체크포인트2/3로 단원 해제돼도 남은 문항 XP는 미지급. 모든 문항 해결 전 마무리 보상 요청은 거부한다.
- 재제출/페이지 재로딩/동시 탭/오프라인 재전송/모드 변경에도 같은 보상은 1회.
