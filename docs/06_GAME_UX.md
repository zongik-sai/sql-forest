# 게임처럼 성취하는 화면과 학습 모드

## 기본 모드
초보자 기본값. 설명 2~4문장→결과 예측→블록/시각 조작→SQL 실행→피드백. 힌트1(개념), 힌트2(방향), 힌트3(부분 코드)를 순서대로 펼친다. 힌트를 사용해도 보상은 동일하다. 기본 모드만으로 Lv99를 달성할 수 있다.

## 도전 모드
같은 목표의 변형 활동을 선택한다. 설명은 접어두고 정답·힌트는 처음 숨기되 '기본 모드로 배우기'로 언제든 전환 가능. 시간제한 없음. 기본 모드 진도·입력은 보존한다. 도전 문제 최소 12개(단원당1개)와 해당 정답·해설을 추가한다. 6시간 필수 코스 바깥의 선택 복습이며 정규 48개 핵심 활동과 별도 ID를 갖는다. XP는 늘리지 않고 별도 숙련 기록·배지만 제공한다.

## 주요 화면
1. 시작 화면: '작은 씨앗으로 시작해 나만의 SQL 숲을 키워보세요.' 성장 미리보기, 6시간 안내, Google 로그인.
2. 나의 정원: 현재 모습, Lv/성장 단계, 다음 레벨 XP, 단원길 12개, '계속 배우기'. XP·전체 학습 진도·진단 정답률은 별도 표시.
3. 학습 화면: 작은 정원 아이콘·레벨·진도만 상단 표시. 콘텐츠를 가리지 않는다. 활동 성공 시 'JOIN으로 두 표를 연결했어요. +100XP'처럼 실제 행동을 설명한다.
4. 레벨업: 비차단 1~2초 토스트. 여러 레벨 상승은 한 번에 Lv12→Lv15로 묶는다. 10·20·…·90·99 성장 변화는 닫기 가능한 짧은 카드.
5. 단원 완료: 배지, 정원 변화, 다음 단원 버튼. 이미 완료한 단원 재방문은 축하 연출을 반복하지 않는다.
6. 숲 완성: Lv99 장면, 배지와 본인 학습 보고서, '보완 개념 복습'. 진단 점수가 낮아도 숲을 빼앗지 않는다.

## 디자인 기준
자연색(연녹색/청록/흙색)과 충분한 텍스트 대비. 유치한 과도한 캐릭터보다 깔끔한 고등학생용 정원. SVG로 잎·가지·나무를 코드에서 생성한다. SQL 표·결과표가 주인공이며 정원은 피드백 역할이다. 사진·외부 이미지 생성 의존 없음.

reduced-motion에서는 애니메이션 없이 최종 장면을 표시한다. 소리는 기본 끔, 켜기 선택. 레벨업 중에도 읽기·SQL 편집 가능. 가림 상태에서는 보상 연출·음성·애니메이션 모두 중단하고 재개 후 묶어서 표시한다. 레벨 보상 때문에 자동 다음 단계로 넘어가지 않는다.

실패 메시지: '결과가 조금 달라요. 어떤 행이 추가됐는지 함께 확인해볼까요?' 실패 횟수를 전면 표시하지 않는다. 오답 기록은 복습 목적에 사용하고 XP 감소·식물 시듦·생명 차감으로 표현하지 않는다.
