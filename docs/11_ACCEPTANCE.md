# 완성 판정·테스트

## 납품 조건
- 12단원·48활동·체크포인트36+재도전36·최초진단5·최종진단12가 콘텐츠 검증기에 통과한다. 각 콘텐츠 ID 중복·참조 누락·힌트/해설 누락 검출.
- 모든 핵심 주제에 실제 활동이 존재하고 미지원 문법은 모드 표시가 있다. U10을 읽기 자료만으로 대체하지 않는다.
- 데모에서 시작→U01→다음단원 해제→초안 저장→복귀→전체 과정→최종 결과까지 실행 가능.
- SQL 에디터가 실제 엔진으로 실행한다. 다른 정답 표현, NULL, 중복행, 순서, 동점, 빈 결과를 올바르게 채점한다.
- typecheck, build, lint(설정한 경우), Vitest, Playwright를 실행하고 결과를 기록한다.

## 의미 있는 자동 검증
1. 기준 seed와 대표 정답 SQL A~E 실행 결과. 모든 실행형 활동의 정답 SQL과 예상 결과 자동 검증.
2. 채점 multiset/순서/NULL/부동소수/별칭 정책, 잘못된 SQL과 대체 정답.
3. Worker 시간초과·금지 SQL·초기화·late result 무시.
4. 집중 상태기계, 타이머 delta, 가림 중 입력·제출 차단, 복귀 시 수동 재개, 초안 보존.
5. 진행 해제/오답 복습/정답 보기 구분, 저장 실패·오프라인 재시도·사용자 전환.
6. Supabase 로컬/테스트 프로젝트에서 사용자 A가 B의 데이터 조회/갱신 불가, UPDATE의 user_id 변경 불가를 실제 정책으로 검사한다.
7. Playwright: 학습 시작, SQL 실행, 다음 활동, 탭 전환, 가림, 재개, 새로고침 복원. 핵심 활동 종류별 1개 이상 조작 검증.

## 수동 확인
Chrome/Edge에서 Alt+Tab, 탭 이동, 최소화, 분할화면 포커스 이동을 확인한다. 자동화의 focus 이벤트만으로 실제 OS 전환 검증을 대체하지 않는다. keyboard-only 조작, overlay contrast, 태블릿 레이아웃, 가림 스크린샷 확인.

Google OAuth는 실제 설정 후 로그인·취소·재로그인·세션만료·다른 기기 이어하기 확인. 자격정보 부재 시 이 항목은 '설정 대기/미검증'이며 mock 성공을 실제 검증으로 보고하지 않는다. 외부 서비스 설정 외 미완성 기능이 있으면 구체적 목록과 이유를 적는다.


## v2 추가 합격 기준
- 0~99 모든 정수의 성장 구간과 정원 상태를 검증한다. 9,900XP 총량, 활동100·문항50·단원100·진단100·마무리900 정책이 일치한다.
- 기본 모드 힌트 사용으로 XP가 줄지 않으며, 안내 활동의 후속 행동 없이 XP가 지급되지 않는다.
- 중복 제출·동시 RPC·오프라인 재전송·버전 변경·모드 변경으로 중복 지급 불가. 클라이언트 xp_events 직접 쓰기가 거부된다.
- 2/3 체크포인트 통과 시 다음 단원 해제, 36개 모두 해결 전 마무리900 미지급. 12단원+전 문항+최종진단+마무리 후 Lv99.
- 도전12개가 기본 과정 밖에서 작동하고 XP 없이 숙련·배지를 남긴다.
- 프로젝트 Pages 경로에서 새로고침/직접 hash 링크/Worker/WASM/에셋을 검증한다. root callback의 code 처리 후 query 제거와 안전한 복귀 경로를 검사한다.
- reduced-motion, 키보드 대체 조작, 화면 가림 상태의 보상 연출 정지·재개를 확인한다.
