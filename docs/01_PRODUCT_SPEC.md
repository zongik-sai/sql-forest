# 제품·학습 흐름

## 목표와 화면
학생이 SQLD 개념 지도를 한 번 돌고 핵심 SQL을 직접 다루는 360분 입문 코스다. 전체 과정 평균 구성은 설명 15%, 활동 65%, 확인·피드백 20%다. 시간은 안내이며 강제 대기나 시간만으로 완료 처리하지 않는다.

1. 시작: 과정 소개, Google 로그인, 개발 데모 버튼(개발 환경만), 학습시간/집중모드 안내.
2. 최초 진단: 5문항, 점수로 단원 잠금을 걸지 않는다. 초보자는 '처음부터 배우기'.
3. 대시보드: 개인 성장 정원·레벨 0~99·경험치·다음 성장 단계, 12단원 지도, 잠김/진행중/완료/복습 상태, 마지막 학습 이어하기, 실제 활동 시간.
4. 단계 화면: 상단 단원·단계·진도, 좌측 짧은 설명, 중앙 인터랙티브 활동, 하단 피드백·힌트·다음.
5. 자유 실습장: 스키마·샘플 데이터·에디터·실행·결과·초기화. 진도와 별개이며 데이터 변경은 격리한다.
6. 오답 복습: 개념 태그별 활동 재도전. 정답 보기 후에는 '설명 확인', 재도전 정답 후에는 '재도전 완료'.
7. 최종 진단/결과표: 레벨99 숲 완성 연출과 함께, 12문항, 영역별 성취·완료 단원·활동 시간·보완 개념. SQLD 합격 예상 점수로 표현하지 않는다.

## 단계와 완료 규칙
단원은 4개 핵심 활동과 마지막 체크포인트 3문항이다. 각 활동은 설명→예측/조작→실행/확인→피드백이다. 직접 입력 활동은 최초에 블록 또는 빈칸 지원 후 직접 SQL로 연결한다.

기본 순서는 U01부터 U12까지. 4개 활동 수행 및 체크포인트 2/3 정답이면 단원 완료·다음 단원 해제. 2/3 미만이면 잘못 이해한 개념을 짧게 복습한 후 체크포인트 재도전. 시간 제한·횟수 제한은 없다. 이미 해제한 단원은 자유 이동 가능. 어려운 활동에서 힌트를 단계적으로 제공한다. 정답 공개 후에는 새 변형 문항을 해결하거나 '안내 학습 완료'로 구분하고, 독립 정답으로 기록하지 않는다.

클릭만 한 경우는 수행이 아니다. 최소 한 번 예측 제출/의미 있는 조작/SQL 실행이 있어야 활동 수행이 된다. 최종 진단은 모든 단원 완료 후 해제하며 진단 점수와 과정 이수는 별개다. 진단을 끝내면 과정 완료. 경험치는 05_GROWTH_SYSTEM.md의 사건별 정책으로 지급한다. 정답률이 낮아도 복습을 안내하며 학습을 차단하지 않는다.

## UX
학교 동아리/캠프/수강신청 사례를 일관되게 사용한다. 표의 행이 어떻게 선택·연결·집계되는지 보여준다. 결과가 다른 이유를 '어느 행에서 차이가 생겼는지'로 설명한다. 애니메이션은 수동 단계 이동과 속도 조절 제공. 드래그 활동에는 버튼/키보드 대안을 제공한다. HTML 표 헤더·에디터 라벨·포커스 이동·aria-live 피드백을 구현한다.

필수 범위는 학생 자기주도 도구다. 교사 대시보드, 학급 관리, AI 챗봇, 실시간 감시는 후속 확장으로 남긴다. 학습 결과 JSON/CSV 다운로드는 제공하되 이메일은 기본 제외한다.

기본 모드는 3단계 힌트·블록·시각화를 항상 제공한다. 도전 모드는 같은 목표의 변형문제를 안내 없이 시도하는 선택 복습이다. 모드 변경으로 단원 잠금을 초기화하거나 중복 경험치를 주지 않는다.
