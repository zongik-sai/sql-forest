# SQL 숲 키우기 v2 — MD와 Claude 제작 프롬프트

레벨0 씨앗에서 레벨99 숲까지 성장하며 SQLD 개념을 체험하는 12단원·360분 자기주도 학습 앱 설계다. 이 패키지는 실행 앱이 아니라 Claude Code에 전달하는 MD 명세와 프롬프트다.

## 사용 순서
1. 이 폴더를 Claude Code의 프로젝트 폴더에서 연다.
2. 00_START_PROMPT.md 전체를 붙여넣는다.
3. Claude가 docs/01~13을 순서대로 읽고 S01~S09를 구현·검증한다.
4. 중간에 멈추면 01_RESUME_PROMPT.md를 붙여넣는다.
5. 앱 완성 후 실제 로그인 설정과 GitHub Pages 연결을 진행한다.

## 파일 순서
- CLAUDE.md: 공통 규칙
- 01_PRODUCT_SPEC: 화면·진도
- 02_CURRICULUM: 12단원360분
- 03_CONTENT_SPEC: 콘텐츠 제작 형식
- 04_DATA_AND_SQL: 기준 데이터·SQL 채점
- 05_GROWTH_SYSTEM: 레벨0~99·9,900XP·중복 방지
- 06_GAME_UX: 기본/도전·정원·축하 피드백
- 07_TECH_SPEC: 앱·SQL Worker
- 08_AUTH_AND_PROGRESS: Google 로그인·저장·원장
- 09_FOCUS_MODE: 화면 가림·일시정지
- 10_BUILD_SEQUENCE: 단계별 구현 순서
- 11_ACCEPTANCE: 테스트·완료 조건
- 12_SETUP_GUIDE: GitHub Pages·Supabase·OAuth
- 13_SOURCES: 공식 자료·검증 상태

기본 모드만으로 숲 완성이 가능하고 힌트 사용으로 경험치를 줄이지 않는다. 6시간은 휴식 제외 예상 시간이며 재도전 속도에 따라 달라진다. Lv99는 학습 과정 완료이며 SQLD 합격 보장이 아니다.
