개인정보처리방침

배움 숲(데이터베이스·컴퓨터 일반·네트워크·프로그래밍·Data·2진법 이해·IP 이해 자기주도 학습 사이트) · 시행일 2026년 10월 26일

배움 숲은 서울인공지능고등학교 담당 교사가 수업용으로 운영하는 무료 학습 사이트입니다. 학습 기록을 저장하고 이어서 공부할 수 있게 하는 데 필요한 정보만 처리합니다. 광고를 하지 않고, 개인정보를 판매하거나 제3자에게 제공하지 않습니다.

1. 처리하는 정보

Google 로그인 정보이메일 주소, Google 프로필 이름, 프로필 사진 주소(Google이 로그인 때 제공하는 기본 정보). 비밀번호는 받지 않습니다.
학습 기록데이터베이스: 단원·활동 진도, 작성 중인 SQL 초안, 활동 시간, 경험치·배지, 진단 답안과 점수
컴퓨터 일반·네트워크·프로그래밍·Data·2진법 이해·IP 이해(과목마다 따로): 단계별 점수와 통과 여부, 개념 맞추기를 마친 카드, 모의고사 결과, 오답노트
모든 과목 공통: 단원 집중 학습 중 화면이 잠긴 시각과 단원 초기화 기록(어느 프로그램·사이트로 갔는지는 알 수 없고 기록하지 않음)
실시간 학습 위치로그인해 공부하는 동안: 지금 보고 있는 과목·단원·단계(활동) 이름과 앱 안의 화면 주소, 진행 위치(카드 n/m, 빈칸 n/m 채움, 문항 n/m, 모의고사 문항 n/m, 활동 n/4, 체크포인트 해결 n/3), 집중 상태(학습 중·잠김·쉬는 중·메뉴·2분 넘게 입력 없음·다른 탭·창), 전체화면 여부, 지금 단원의 잠김 횟수, 화면 공유 중인지, 기기 구분용 임의 번호(여러 기기를 구분하는 데만 쓰며 다른 정보와 연결하지 않음)
보내는 때: 사이트를 열어 둔 동안 15초마다, 그리고 위치가 바뀌면 바로(숨긴 탭은 숨길 때 한 번만, 같은 브라우저의 여러 탭은 앞에 있는 탭만)
보관: 학생마다 가장 최근 한 건만 남기고 보낼 때마다 덮어씁니다(지난 위치 기록을 쌓지 않음)
볼 수 있는 사람: 담당 선생님만, 최근 몇 시간(최대 4시간) 안에 보낸 것만 보입니다. 화면 내용·키 입력·방문한 다른 사이트는 보내지 않습니다. 학습 화면 상단에 '학습 위치 공유 중'으로 표시합니다(집중 학습 잠김 화면이 덮고 있는 동안에는 가려짐).
화면 공유선생님이 요청하고 학생이 매번 허락할 때만, 학생이 브라우저 창에서 직접 고른 화면(탭·창·전체 화면)을 선생님 화면에 실시간으로 보여 줍니다. 영상은 학생과 선생님의 브라우저 사이에서 직접 오가며 서버를 거치지 않고, 녹화·저장하지 않습니다. 서버에는 브라우저끼리 연결하는 데 필요한 연결 정보(양쪽 기기의 IP 주소 등 네트워크 주소가 들어 있음)만 잠시 오가고, 공유가 끝나거나 몇 분 안에 연결되지 않으면 지웁니다(요청 기록은 하루 뒤 정리). 한 번 허락한 공유는 길어도 1시간 뒤 저절로 끝납니다. 공유 중에는 '선생님에게 화면을 보여 주는 중' 표시가 늘 보이고, 학생은 언제든 '공유 중지'로 멈출 수 있습니다.
이 브라우저에 저장로그인 유지 정보와 학습 기록 사본(인터넷이 끊겨도 이어서 공부하기 위함). 로그아웃하면 이 기기의 기록 사본을 지웁니다. 로그인 없이 공부하면 그 기기에만 저장됩니다.

학번·주민등록번호·전화번호는 받지 않습니다. 화면 내용(화면 공유는 학생이 허락할 때 실시간으로만 보여 주고 저장하지 않음), 키 입력, 방문한 다른 사이트, 다른 프로그램 정보는 수집하지 않습니다. SQL 실습은 학생의 브라우저 안에서만 실행되며 서버로 보내지 않습니다.

2. 이용 목적

  • 학습 기록 저장과 다른 기기에서 이어 공부하기
  • 담당 교사의 학습 지원: 반 학습 현황(진도·점수 요약)을 보고 수업에 활용
  • 수업 중 실시간 학습 지원: 누가 어디를 공부하고 있는지, 도움이 필요한지(잠김·자리 비움) 확인하고, 학생이 허락하면 화면을 함께 보며 도와주기

점수는 학생 브라우저가 계산해 저장하는 자기 학습 기록이며, 성적이나 출결 평가 근거로 쓰지 않습니다.

3. 저장 위치와 열람할 수 있는 사람

  • 저장 위치: Supabase(데이터베이스 서비스) 서울 리전 서버
  • 학생은 자기 기록만 보고 고칠 수 있습니다(데이터베이스 접근 규칙으로 다른 학생 기록 접근을 막습니다).
  • 지정된 담당 교사 계정은 학생들의 기록과 실시간 학습 위치를 읽기만 할 수 있습니다. 화면은 학생이 그때마다 허락할 때만 볼 수 있습니다.
  • 로그인은 Google이 처리하며, 사이트는 Google 비밀번호를 받거나 저장하지 않습니다.

4. 보관 기간과 삭제

  • 학습 기록은 해당 학년도 수업 기간 동안 보관하고, 학년도가 끝난 뒤 1년 안에 정리합니다.
  • 데이터베이스 과목 기록은 "나의 정원" 화면 아래 내 학습 기록 지우기로 직접 지울 수 있습니다.
  • 실시간 학습 위치는 학생마다 가장 최근 한 건만 남아 계속 덮어쓰며, 화면 공유 연결 정보(IP 주소 포함)는 공유가 끝나거나 만료되면 지웁니다.
  • 컴퓨터 일반·네트워크·프로그래밍·Data·2진법 이해·IP 이해 기록 삭제나 계정 삭제를 원하면 담당 선생님께 말해 주세요. 계정을 지우면 연결된 모든 학습 기록이 함께 지워집니다.
